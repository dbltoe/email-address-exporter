[SIZE=4][B]Installing[/B][/SIZE]

It installs into your store's [B]root[/B] — the folder that also holds YOUR_ADMIN, includes/, email/ and logs/. Upload the download's zc_plugins/ folder there, [B]merging[/B] it into the zc_plugins/ folder already present, so you end up with:

[CODE]<your store root>/zc_plugins/EmailAddressExporter/v3.0.0/manifest.php[/CODE]

Then install it from [B]Modules → Plugin Manager[/B]. The page appears under [B]Tools → Export Email Addresses[/B].

If you end up with zc_plugins/zc_plugins/, the folder went one level too deep — move EmailAddressExporter up one level and delete the empty inner folder. Plugin Manager will not list the plugin until that is right.

Upgrading from an earlier version: uninstall the old one in Plugin Manager first. No data is affected — the plugin creates no tables and modifies no records.

Full documentation ships with it as readme.html, and is linked from the Plugin Manager panel alongside the Install button.
